# งานค้าง — แอปเตือนงานที่ต้องส่ง

จดงานที่ค้างไว้พร้อมวันครบกำหนด แล้วให้ระบบ **เตือนทุกเช้า 7 โมง** ว่ามีงานค้างอะไรบ้าง
ต้องส่งวันไหน — ส่งเข้ามือถือแบบ push แม้ไม่ได้เปิดแอปค้างไว้

> แอปนี้อยู่คนละสาขากับ “ครัวขนม” (ระบบต้นทุนร้านขนม) ที่อยู่บนสาขา `main`

## ใช้งานยังไง

1. เปิดแอป จดงานที่ต้องส่ง เลือกวันครบกำหนด (มีปุ่มด่วน วันนี้ / พรุ่งนี้ / +7 วัน)
2. กด **“เปิดรับเตือน”** แล้วอนุญาตการแจ้งเตือนของเบราว์เซอร์
3. ทุกเช้า 7 โมง (เวลาไทย) จะได้การแจ้งเตือนสรุปงานค้าง เรียงตามวันครบกำหนด
   งานที่เลยกำหนดจะขึ้นก่อนพร้อมป้าย ⚠️
4. ติ๊กงานที่เสร็จแล้วออกได้ งานที่เสร็จจะไม่ถูกนำมาเตือน

### ใช้สองเครื่อง

งานถูกซิงค์ตาม **“รหัสของคุณ”** (สุ่มให้อัตโนมัติครั้งแรก) ดูรหัสได้ในแผงแจ้งเตือน
อยากดูงานชุดเดียวกันบนเครื่องอื่น ให้กด “ใช้รหัสอื่น” แล้ววางรหัสเดิมลงไป
เปิดรับเตือนบนเครื่องไหน เครื่องนั้นก็จะได้การแจ้งเตือนของรหัสนั้น

### บน iPhone

Safari ให้ push ได้เฉพาะเว็บที่ถูก “เพิ่มไปยังหน้าจอโฮม” ก่อน — กดปุ่มแชร์ใน Safari
→ “เพิ่มไปยังหน้าจอโฮม” แล้วเปิดแอปจากไอคอนนั้น จึงจะเปิดรับเตือนได้

## โครงสร้าง

| ส่วน | ไฟล์ | หน้าที่ |
| --- | --- | --- |
| หน้าเว็บ (PWA) | `src/` | React + Vite + Tailwind |
| ตรรกะงาน/วันที่ | `src/lib/tasks.ts` | นับค้าง, จัดเรียง, รวมงานตอนซิงค์ (ทดสอบได้) |
| ซิงค์ | `src/lib/sync.ts`, `src/lib/store.tsx` | เก็บในเครื่อง + ซิงค์เซิร์ฟเวอร์ กันชนด้วย version |
| แจ้งเตือน (ฝั่งเว็บ) | `src/lib/push.ts`, `public/sw.js` | สมัคร Web Push + service worker |
| เก็บงานกลาง | `netlify/functions/tasks.mjs` | อ่าน/เขียนงานตามรหัส (Netlify Blobs) |
| อุปกรณ์รับเตือน | `netlify/functions/push.mjs` | เพิ่ม/ลบการสมัคร + ส่งทดสอบ |
| ตัวตั้งเวลา | `netlify/functions/notify.mjs` | รันทุก 00:00 UTC = 7 โมงเช้าไทย ส่ง push |
| สรุปข้อความ | `netlify/functions/_notify.mjs` | สร้างข้อความเตือน (ทดสอบได้) |

## คำสั่ง

```bash
npm install
npm run dev      # รันหน้าเว็บตอนพัฒนา
npm test         # เทสต์ตรรกะงาน วันที่ และ API
npm run build    # สร้างไฟล์สำหรับเผยแพร่
npm run lint
```

การแจ้งเตือนจริง (Web Push + ตัวตั้งเวลา) ต้องเผยแพร่บน Netlify — ดู
