# 🍡 ระบบวางแผนปริมาณขนม (Khanom Planner)

ระบบช่วยคำนวณว่า **แต่ละวันควรทำขนมกี่ชิ้นเพื่อไปขาย** โดยดูจาก **ประวัติการขายย้อนหลัง**
แล้วใช้หลักสถิติ 2 ตัวหลักคือ **ค่าเฉลี่ยเลขคณิต** และ **ส่วนเบี่ยงเบนมาตรฐาน**

ใช้งานง่ายบนเบราว์เซอร์ ไม่ต้องติดตั้งอะไร ไม่ต้องต่ออินเทอร์เน็ต และข้อมูลเก็บไว้ในเครื่องคุณเอง

## วิธีใช้งาน

1. เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ (ดับเบิลคลิกได้เลย)
2. กด **➕ เพิ่มชนิดขนม** ใส่ชื่อและหน่วย (เช่น ขนมครก / ชิ้น)
3. บันทึก **ยอดขายย้อนหลัง** ของแต่ละวัน (วันที่ + ขายได้กี่ชิ้น)
4. ระบบจะแสดง **ปริมาณที่แนะนำให้ทำ** พร้อมสถิติทันที

> 💡 อยากลองดูผลก่อน กดปุ่ม **🎲 ใส่ข้อมูลตัวอย่าง** เพื่อสร้างข้อมูลย้อนหลัง 3 สัปดาห์

## หลักการคำนวณ

```
ปริมาณที่แนะนำ  =  ค่าเฉลี่ยเลขคณิต  +  ( z × ส่วนเบี่ยงเบนมาตรฐาน )
                    └─ ยอดขายเฉลี่ย ─┘   └──── สต็อกเผื่อ ────┘
```

- **ค่าเฉลี่ยเลขคณิต (mean)** — ยอดขายที่คาดว่าจะขายได้โดยเฉลี่ยต่อวัน
- **ส่วนเบี่ยงเบนมาตรฐาน (SD)** — บอกว่ายอดขายแต่ละวัน "แกว่ง" มากแค่ไหน
  (ใช้สูตรตัวอย่าง หารด้วย n−1 เพราะเป็นข้อมูลตัวอย่างที่ใช้ทำนายอนาคต)
- **สต็อกเผื่อ (safety stock)** — ปริมาณที่ทำเพิ่มเพื่อกันขนมขาดในวันที่ขายดี
  ยิ่งตั้ง "ความมั่นใจว่าขนมจะพอขาย" สูง ค่า `z` ยิ่งมาก ทำเผื่อยิ่งเยอะ

### ตัวเลือก "ความมั่นใจว่าขนมจะพอขาย"

ปรับได้ด้วยแถบเลื่อน (50%–99%) — แปลงเป็นค่า `z` ด้วยการแจกแจงปกติ

| ความมั่นใจ | ค่า z โดยประมาณ | เหมาะกับ |
|-----------|----------------|---------|
| 50%       | 0.00           | ประหยัดสุด เน้นไม่ให้เหลือ (แต่เสี่ยงขาด) |
| 85%       | 1.04           | สมดุล (ค่าเริ่มต้น) |
| 95%       | 1.64           | เน้นให้พอขายเกือบทุกวัน |

### คิดแยกตามวันในสัปดาห์

เปิดตัวเลือกนี้เมื่อยอดขายต่างกันชัดตามวัน (เช่น เสาร์-อาทิตย์ขายดีกว่า)
ระบบจะคำนวณเฉพาะประวัติของวันที่เลือกไปขาย (ถ้าข้อมูลวันนั้นยังน้อยกว่า 2 วัน
จะกลับไปใช้ข้อมูลทุกวันชั่วคราว)

## โครงสร้างไฟล์

```
index.html        หน้าจอหลัก
css/style.css      สไตล์
js/stats.js        โมดูลคำนวณสถิติ (ฟังก์ชันบริสุทธิ์ ทดสอบได้)
js/app.js          ตัวควบคุมหน้าจอ + เก็บข้อมูลใน localStorage
test/stats.test.js ชุดทดสอบการคำนวณ
```

## การทดสอบ

```bash
npm test        # หรือ  node test/stats.test.js
```

## หมายเหตุเรื่องข้อมูล

ข้อมูลถูกเก็บใน `localStorage` ของเบราว์เซอร์เครื่องนี้เท่านั้น หากล้างข้อมูลเบราว์เซอร์
หรือเปลี่ยนเครื่อง ข้อมูลจะหาย จึงควรกด **⬇️ ดาวน์โหลดข้อมูลสำรอง** ไว้เป็นระยะ
