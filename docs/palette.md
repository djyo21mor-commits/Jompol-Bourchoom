# ชุดสีของกราฟ

สีที่ใช้ในกราฟทั้งหมด (`src/components/Charts.tsx`) ถูกเลือกให้ผ่านเกณฑ์ต่อไปนี้
ทั้งในโหมดสว่างและโหมดมืด แล้วประกาศเป็นตัวแปร `--c-s1` … `--c-s5` ใน `src/index.css`

| ช่อง | ใช้กับ | โหมดสว่าง | โหมดมืด |
| --- | --- | --- | --- |
| s1 | ยอดขาย, ค่าวัตถุดิบ | `#2a78d6` | `#3987e5` |
| s2 | ต้นทุนผลิต, ค่าแรง | `#eb6834` | `#d95926` |
| s3 | ค่าน้ำ | `#1baf7a` | `#199e70` |
| s4 | ค่าไฟ | `#eda100` | `#c98500` |
| s5 | ค่าจิปาถะ | `#e87ba4` | `#d55181` |

สีบอกสถานะแยกออกจากสีกราฟ ไม่นำมาใช้ปนกัน:
`--c-good #0ca30c` · `--c-warn #fab219` · `--c-bad #d03b3b`

## ผลการตรวจ

ตรวจด้วยสคริปต์ `validate_palette.js` ของชุดทักษะ dataviz โดยใช้พื้นหลังจริงของการ์ดในแอป
(`#ffffff` โหมดสว่าง, `#1e1a17` โหมดมืด)

```
โหมดสว่าง (พื้น #ffffff)
  [PASS] ช่วงความสว่าง        ทั้ง 5 สีอยู่ในช่วง L 0.43–0.77
  [PASS] ความอิ่มตัวขั้นต่ำ    ทั้ง 5 สี >= 0.1
  [PASS] แยกได้เมื่อตาบอดสี    คู่ที่แย่ที่สุด #eda100↔#1baf7a ΔE 9.1 (protan)
  [PASS] แยกได้ด้วยตาปกติ      คู่ที่แย่ที่สุด #e87ba4↔#eda100 ΔE 19.6
  [WARN] contrast กับพื้นหลัง  3 สีต่ำกว่า 3:1

โหมดมืด (พื้น #1e1a17)
  ผ่านทั้ง 5 ข้อ — contrast ทุกสี >= 3:1
```

คำเตือน contrast ในโหมดสว่างถูกชดเชยตามข้อกำหนด คือกราฟทุกตัวมี **ป้ายตัวเลขกำกับ**
และ **มุมมองตาราง** ให้สลับดูได้ สีจึงไม่ใช่ตัวสื่อความหมายเพียงอย่างเดียว

## ถ้าจะเปลี่ยนสี

แก้ค่าใน `:root` และ `.dark` ของ `src/index.css` แล้วรันตรวจใหม่ก่อนใช้งานจริง:

```bash
node <path-to-dataviz-skill>/scripts/validate_palette.js \
  "#2a78d6,#eb6834,#1baf7a,#eda100,#e87ba4" --mode light --surface "#ffffff"
```
