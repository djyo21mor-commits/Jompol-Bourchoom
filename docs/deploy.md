# เผยแพร่บน Netlify

การแจ้งเตือน 7 โมงเช้าต้องมี 3 อย่างทำงานร่วมกัน — เว็บ (PWA), ที่เก็บข้อมูล (Netlify Blobs),
และฟังก์ชันตั้งเวลา (scheduled function) ทั้งหมดนี้ได้มาในตัวเมื่อ deploy บน Netlify

## ขั้นตอน

1. สร้างไซต์ใหม่บน [Netlify](https://app.netlify.com/) เชื่อมกับ repo นี้
   เลือก **branch** เป็นสาขาของแอปนี้ (ไม่ใช่ `main` ซึ่งเป็นแอปครัวขนม)
2. ค่าตั้ง build ถูกกำหนดไว้ใน `netlify.toml` แล้ว (build = `npm run build`, publish = `dist`,
   functions = `netlify/functions`) — ไม่ต้องแก้อะไร
3. กด Deploy รอจนเสร็จ แล้วเปิดลิงก์ของไซต์ กด “เปิดรับเตือน”

Netlify จะเปิด **Blobs** ให้อัตโนมัติ (ใช้เก็บงานและรายการอุปกรณ์) และตรวจเจอ
`export const config = { schedule: '0 0 * * *' }` ใน `notify.mjs` แล้วตั้งเวลารันให้เอง

## เวลาเตือน

Netlify นับเวลาแบบ UTC — 7 โมงเช้าเวลาไทย (UTC+7) ตรงกับ `00:00 UTC`
จึงตั้ง cron ไว้ `0 0 * * *` ใน `netlify/functions/notify.mjs`
ถ้าอยากเปลี่ยนเวลา แก้บรรทัด `schedule` (เป็นเวลา UTC เสมอ เช่นอยากเตือน 6 โมงเช้าไทย = `0 23 * * *`)

## กุญแจ VAPID (สำหรับเซ็นข้อความ Web Push)

โปรเจกต์แนบกุญแจชุดปริยายมาให้แล้ว ใช้ได้ทันที แต่ **ควรสร้างชุดใหม่เมื่อใช้จริง**
เพราะกุญแจลับที่แนบมาเปิดเผยในโค้ด (ใครถือกุญแจลับนี้ส่งแจ้งเตือนหาอุปกรณ์ที่สมัครไว้ได้)

สร้างชุดใหม่:

```bash
npx web-push generate-vapid-keys
```

แล้วตั้งเป็น **Environment variables** ของไซต์บน Netlify
(Site settings → Environment variables):

| ชื่อ | ค่า |
| --- | --- |
| `VAPID_PUBLIC_KEY` | คีย์สาธารณะที่ได้ |
| `VAPID_PRIVATE_KEY` | คีย์ลับที่ได้ |
| `VAPID_SUBJECT` | `mailto:อีเมลคุณ` |

หน้าเว็บดึงคีย์สาธารณะจาก `/api/push` ตอนสมัคร จึงไม่ต้องแก้โค้ดฝั่งเว็บ
เมื่อเปลี่ยนคีย์แล้ว ให้ทุกเครื่องกด “ปิด” แล้ว “เปิดรับเตือน” ใหม่อีกครั้ง

## ทดสอบ

- ในแอปมีปุ่ม **“ส่งแจ้งเตือนทดสอบเดี๋ยวนี้”** (โผล่หลังเปิดรับเตือน) ยิง push ทันทีโดยไม่ต้องรอเช้า
- อยากลองตัวตั้งเวลาเอง: เข้า Netlify → Functions → `notify` → กด run
